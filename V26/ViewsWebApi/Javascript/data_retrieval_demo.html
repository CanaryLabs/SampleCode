Views API Demo

Before using the API, the proper endpoints must be turned on to listen for requests. This demo has been configured to read data from a views service and historian running on the local machine.

  1. Open the "Canary Admin" program.
  2. Click on the "Views" info box on the home screen.
  3. Click on "Configuration" in the bottom tab control.
  4. Click on "Endpoints" in the side tab control.
  5. Turn on the (Web API) endpoint. Note the port number. This is the port that will be listening for the Web API requests.

Requests are authenticated with an api token instead of a user name and password.

  1. Click on the "Identity" info box on the home screen.
  2. Click on "Security" in the bottom tab control, then "API Tokens".
  3. Create an api token and set "_apiToken" in the page source to its value. The token can also be sent as an "Authorization: Bearer" header.

Click on the buttons to execute method calls to an api on the local machine. The results of each method call are shown in the "Results" section, and in the browser console (F12).

  1. Call "GetTimeZones" and set "_timeZone" to the "timezone" that should be used when returning timestamps.
  2. Call "BrowseTags" to load a tag array used to retrieve data in subsequent calls.
  3. Call "GetCurrentValue" to get current values of the tag array.
  4. Call "GetRawData" to get raw data of the tag array.
  5. Call "GetProcessedData" to get processed data of the tag array.
